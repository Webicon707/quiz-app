# 🧠 Interactive Quiz Application

A clean and interactive Quiz Application built using pure frontend technologies. It allows users to test their knowledge with real-time scoring and instant feedback.

## 🚀 Key Features
* **Dynamic Loading:** Questions load automatically one after another.
* **Instant Feedback:** Shows immediately if your answer is correct (Green) or wrong (Red).
* **Score Summary:** Displays the final total score at the end of the quiz.
* **Responsive UI:** Works perfectly on both smartphones and desktops.

## 🛠️ Technologies Used
* **HTML5:** For layout and structure.
* **CSS3:** For clean styling and responsive design.
* **Vanilla JavaScript:** For core game logic and score tracking.

## 📂 How to Run
1. Download or clone this project folder.
2. Double-click the `index.html` file to open it in your web browser.
